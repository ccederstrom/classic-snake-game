# classic-snake-game

Classic Snake game implemented as a small vanilla web app.

## Run locally

1. Start a local server:
   ```bash
   npm start
   ```
2. Open: <http://localhost:4173>

## Test

```bash
npm test
```

## Manual verification checklist

- [ ] Arrow keys and WASD both move the snake.
- [ ] Snake cannot reverse direction into itself.
- [ ] Eating food increases score and length.
- [ ] Wall/self collision triggers game over.
- [ ] Restart button resets game state and score.
- [ ] Pause/Resume works via Space key and button.
